# MoneyPrinterTurbo — System Architecture and Production Map

> **Baseline:** commit `b819f7e`, tag `v1.3.8`, snapshot 2026-10-15.
> Uncommitted `openai_image` scene-pipeline feature present in working tree.

## Overview

MoneyPrinterTurbo generates short-form narration videos. The user provides a
subject; the system generates a script, synthesizes narration audio, retrieves
or generates video materials, composes a final video with subtitles and
background music, and optionally publishes to social platforms.

## Data Contracts

### Script Paragraphs

Parsed by `llm.split_script_paragraphs()` (line 972): splits on blank lines
(`\n\s*\n+`), normalizes `\r\n` and `\r`, strips whitespace, discards empty
blocks. This is the single parsing convention — both counting and text
extraction use it.

### Scene Descriptions

- **Type:** `List[str]` — one non-empty string per script paragraph.
- **Storage:** `params.video_scene_descriptions` (schema.py line 109),
  persisted in `script.json` via `save_script_data()`.
- **Contract:** `len(scene_descriptions) == count_script_paragraphs(script)`.
  Violation causes task failure at stage `"scene_descriptions"`.

### Scene Durations

- **Type:** `List[float]` — one duration per scene, in seconds.
- **Allocation:** `allocate_scene_durations()` (task.py line 500) distributes
  `audio_duration` proportionally by `count_paragraph_words()`.
- **Contract:** `len(durations) == len(paragraphs)`, `sum(durations) ≈ audio_duration`
  (within one frame at 30 fps), each `duration ≥ 1/30`.
- **FPS alignment:** `SCENE_DURATION_FPS = 30` (task.py line 484) matches
  `fps = 30` (video.py line 78). These are separate constants in separate files.

### Video Composition

`combine_videos()` behavior differs by mode:

| Mode | Speed Scaling | Duration Cap | Reordering | Loop | Scene Validation |
|------|--------------|-------------|------------|------|-----------------|
| Standard | Applied | `max_clip_duration` | Per concat mode | Yes, to fill audio | None |
| `preserve_scene_clips` | Skipped | Skipped | Preserved | None | Count + coverage |

### Task State

Fields preserved on failure (`_mark_task_failed`, line 290):
`videos`, `combined_videos`, `warnings`, `failed_video_index`,
`video_scene_descriptions` (uncommitted).

## Configuration

Configuration is loaded from `config.toml` (project root) with fallback to
`config.example.toml`. Key sections:

- `[app]` — API keys, LLM provider, video source, voice settings
- `[ui]` — WebUI defaults, prompts, subtitle styling
- `[whisper]` — Local subtitle model settings
- `[azure]`, `[elevenlabs]`, `[minimax_tts]`, etc. — Provider-specific settings

A backup exists at `config.toml.backup-20261010-223608` showing the config
state before recent prompt iterations.
